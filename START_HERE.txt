CÁCH 1: CHỈ FRONTEND (OFFLINE - NHANH NHẤT)

  1. Mở file: index.html (double-click hoặc kéo vào browser)
  2. Chụp ảnh → OCR → Copy kết quả
  3. Gửi email thủ công bằng Gmail/Outlook
  
  ✓ Xong! Không cần cài gì.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CÁCH 2: THÊM BACKEND (GỬI EMAIL TỰ ĐỘNG)

  Bước 1: Cài Node.js
    $ node --version  (kiểm tra)
  
  Bước 2: Setup backend
    $ npm install
    $ cp .env.example .env
    # Sửa .env: EMAIL_USER, EMAIL_PASSWORD
  
  Bước 3: Test email
    $ npm run test
    # Nếu OK → nhận email test
  
  Bước 4: Chạy server
    $ npm start
    # Truy cập: http://localhost:3000
  
  ✓ Xong! Backend chạy local.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CÁCH 3: DEPLOY LÊN CLOUD (CÔNG KHAI)

  📝 Hướng dẫn chi tiết trong DEPLOY.md
  
  Nhanh nhất (1 phút):
    1. Push GitHub
    2. Vào Vercel.com → "Deploy from GitHub"
    3. Cấu hình Environment Variables
    4. ✓ Xong! Link public
  
  💰 Miễn phí trên: Vercel, Heroku, Railway, Netlify

📧 EMAIL SETUP (Nếu dùng backend)

  Gmail (khuyến nghị):
    1. https://myaccount.google.com/security
    2. Bật "2-Step Verification"
    3. https://myaccount.google.com/apppasswords
    4. Chọn "Mail" → Copy 16 ký tự
    5. Paste vào .env: EMAIL_PASSWORD=xxxx-xxxx-xxxx-xxxx

  Alternative: Outlook, SendGrid, Custom SMTP
